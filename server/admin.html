Sign in

As the administrator: the user named by ADMIN_USER in the server's .env, admin unless it says otherwise. Its password is in the server's secrets folder.

The people who may sign in to DJV, and to the portal, with this server. Give each one a name and a password; they type both into DJV's Sync Server settings once.
